# Language Constraint: Do Not Use French

- **Strict Constraint**: Do NOT use the French language in user responses, discussions, summaries, plans, or explanations.
- **Language Requirement**: Always communicate with the user strictly in English.
- **Exceptions**: Project UI strings that are already localized for Moroccan customers or specific store configurations may remain untouched in code, but all conversation, assistant reasoning output, documentation, and user messages must be in English.
